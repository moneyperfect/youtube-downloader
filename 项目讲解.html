Part I

功能介绍

单视频下载

粘贴 YouTube 链接即可下载。自动选择最佳画质（优先 H.264 编码），视频与音频自动合并为 MP4 格式，兼容性最强。

批量下载

支持多行粘贴，每行一个链接，一键提交多个下载任务。后台并发执行，互不阻塞。

画质选择

提供 1080p 高清、720p 标清、480p 流畅、仅音频四种模式，按需选择，节省存储空间。

实时进度

每秒轮询下载状态，进度条实时更新。显示下载速度、剩余时间、文件大小等详细信息。

桌面通知

下载完成时弹出浏览器桌面通知，点击即可打开文件所在目录。支持多任务并行通知。

历史搜索

下载历史支持关键字搜索过滤，快速定位已下载的视频文件。

安全防护

URL 白名单验证（仅允许 YouTube）、请求速率限制、可选密码认证、CORS 收紧，多重安全保障。

局域网访问

支持局域网内其他设备访问，自动生成二维码，手机扫码即可使用。

断点续传

利用 yt-dlp 的续传能力，网络中断后可继续下载，无需重新开始。

Part III

工作原理

1

用户粘贴链接

在前端输入框粘贴 YouTube 链接（支持批量，每行一个）。选择画质后点击下载。前端先进行 URL 格式校验，确认为 YouTube 域名后发送 POST 请求到后端。

2

后端安全校验

Express 中间件依次执行：CORS 检查、速率限制（10 次/分钟）、密码认证（可选）、URL 白名单验证。任一环节失败立即返回错误码，不进入下载流程。

3

创建下载任务

VideoDownloader 生成 8 位随机 task_id，创建 DownloadTask 对象存入内存 Map。任务状态初始化为 pending，随后启动后台子进程。

4

调用 yt-dlp 二进制

通过 child_process.spawn 启动 yt-dlp 进程，传入格式选择、代理、Cookies、重试策略等参数。画质映射为 yt-dlp 的 -f 格式字符串。

5

实时解析进度

yt-dlp 以 --newline 模式输出，每行一个进度更新。后端正则匹配下载百分比、文件大小、速度、剩余时间，更新 Task 对象。

6

前端轮询展示

app.js 每秒对所有活跃任务发送 GET /api/status/:taskId。收到响应后更新 DOM：进度条宽度、百分比文字、速度与 ETA 信息。

7

合并与完成

视频流和音频流下载完成后，yt-dlp 自动调用 FFmpeg 合并为 MP4。后端检测到进程退出码为 0，将状态设为 completed，并找到最终文件名。

8

通知与归档

前端检测到状态变为 completed，触发桌面通知（如已授权）。用户可点击播放打开文件，或点击文件夹打开下载目录。已下载文件支持搜索过滤。

Part IV

开发过程

Phase 1 - 原型

Python + FastAPI 快速原型

最初使用 Python FastAPI 作为后端，通过 subprocess 调用 yt-dlp CLI。前端使用原生 HTML/CSS/JS，实现基本的单视频下载和进度显示。UI 采用文艺复兴羊皮纸风格，确立了 Studio Aureo 的视觉基调。

Python 3.12 FastAPI yt-dlp imageio-ffmpeg

Phase 2 - 安全加固

安全性与稳定性提升

产品评分发现安全性（4/10）和稳定性（5/10）低于及格线。实施了 URL 白名单验证、CORS 收紧、速率限制、可选密码认证。添加了错误分类系统，将 yt-dlp 的英文错误映射为友好中文提示。实现了超时检测和重试按钮。

URL 验证 速率限制 错误分类 超时检测

Phase 3 - 功能补全

批量下载与用户体验

功能完整性评分仅 4/10。新增批量下载（多行 URL 一次提交）、画质选择（1080p/720p/480p/仅音频）、下载速度与 ETA 显示、历史记录搜索、可持久化设置面板。

批量下载 画质选择 速度/ETA 搜索过滤

Phase 4 - 技术栈迁移

Python 到 Node.js 重写

考虑到分发需求（用户无需安装 Python 运行时），将整个后端从 Python FastAPI 迁移到 Node.js Express。yt-dlp 从 Python 包调用改为二进制子进程调用。配置从 YAML 改为 JSON。实现了自研日志模块。可通过 pkg 打包为单个 exe 文件分发。

Node.js Express child_process pkg 单文件打包

Part VI

API 文档

方法 路径 说明
GET /api/info 获取视频元数据（标题、时长、缩略图、上传者）
POST /api/download 启动单个下载任务，body: {url, proxy?, quality?}
POST /api/download/batch 批量下载，body: {urls[], proxy?, quality?}
GET /api/status/:taskId 轮询下载进度，返回 status / progress / speed / eta
GET /api/files 列出已下载文件（名称、大小）
GET /api/open-folder 在系统文件管理器中打开下载目录
GET /api/qr 生成局域网访问二维码（Base64 图片）
GET /api/health 健康检查，返回活跃任务数和下载目录
